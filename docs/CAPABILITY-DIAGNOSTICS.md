# 外部能力與失敗診斷

2026-11-13。Discord 設定新增「外部能力與診斷」，統一讀取語音合成、辨識、記憶交付、知識查詢、音樂、翻唱、通訊交付、心情與 DSH 排程的狀態。各插件維持獨立。

## 五層證據

| 層次 | 依據 | 不能推論什麼 |
|---|---|---|
| 安裝 | 當前 DSH profile 的 pluginManager 清單及執行中插件 | 電腦其他位置下載過，不等於當前 profile 已安裝 |
| 載入 | 執行中插件的 active／loading 狀態 | 某個服務／工具已註冊，不等於所有相依插件已載入 |
| 設定就緒 | 服務回報、模型準備狀態、介面契約及當前選擇 | 不代表金鑰、音色、後端或遠端目的地已成功使用 |
| 介面契約模擬 | 隨套件附帶、綁定本插件來源雜湊的測試基線 | 只驗本插件介面卡與替身契約，不驗所有外部版本、帳號與引擎 |
| 最近實際呼叫 | 本次啟動、自然使用時回傳的單次操作結果 | 不代表所有會話／工作區可用、遠端聽到聲音或記憶完成提煉 |

不確定就顯示未知。工具存在、檔案候選已匯出、待審記憶、預演成品及桌面播放都不直接變成「實測通過」。更新狀態只讀清單／服務快照，不合成、不送錄音、不搜尋、不寫記憶、不建立排程、不下載或翻唱，也不加入房間。

宿主清單不可用會保留未知，單一未就緒來源不應使全部能力變成可用。其他 TTS 插件可列出安裝狀態，但未被選用或無明確音訊接口時，不宣稱已接入。

## 使用介面

- 可依類別、名稱、接口、能力或錯誤權限搜尋，並只看需要處理的項目。
- 顯示各能力的來源、對應 Discord 開關、接口可見性、支援／不支援／待確認與修復提示。
- 「前往相關設定」導向本插件現有設定分區；不自動代填金鑰、改權限、下載模型或啟用原插件。
- 「目前語音收聽對象與費用」區分收聽、同意、允許名單、AI 自動回覆與 STT 秒數預算，不顯示名單 ID。房內待命不持續消耗 LLM Token；本機 STT 用運算資源，雲端 STT／TTS 可能另計費。

## 觀測與失敗分類

目前在本插件自己的 TTS 完整／串流、STT、記憶寫入回執、原生 DSH 查詢工具結果、音樂搜尋／讀取、固定翻唱階段、排程建立與 Discord 語音傳輸路徑觀測結果。不改第三方全域工具、不另發測試請求，也不以模型自稱成功作為證據。

成功的串流須完整消費且非空；提前結束、取消與例外不算完整成功。記憶需 stored／deduplicated 及有效 ID 才確認，待審／只接受／檔案匯出仍是未確認。翻唱環境檢查不等於取得真實成品，排程建立不等於到期已喚醒，音樂搜尋不等於播放。

失敗統一分類為授權、權限、額度、頻率、逾時、接口離線／變更、服務暫不可用、設定、能力不支援、範圍、取消、結果不明、回傳格式或未知。可顯示 HTTP 狀態及固定允許的 models_read／voices_read 權限提示，附修復建議。結果不明先核對，不自動重送。

只留能力 ID、操作類型、時間、耗時、結果、來源指紋與固定錯誤分類，不保留原始錯誤、聊天、逐字稿、查詢字串、音訊、記憶內容或憑證。記錄最多 300 個能力／證據類別鍵，RAM 保存，重啟清空；同一能力只保留最近一筆結果。沒有可由網頁 POST 宣稱通過驗證的接口。

來源／設定指紋改變或超過 24 小時，呼叫證據標為舊證據；接口卸載後仍可顯示其曾出現的紀錄與目前缺失，不能沿用舊成功。舊範圍失敗原因與當前失敗分開顯示。指紋只涵蓋可觀測的來源與設定，不保證能發現外部服務內部偷偷更換金鑰等變動。

隔離模擬的呼叫另列，永不提升為實際呼叫；原生工具結果依 callId 配對，包含內層 ok:false 的失敗。不複製工具返回正文。

## 特別界線

- dsh-voice 的橋接註冊不代表原插件或聽寫鏈就緒；不額外呼叫原服務確認。本機／雲端處理方式在未知時不猜測。
- memU 的寫入工具存在不證明目前工作區綁定、後端與入庫正常。其他記憶系統的正式會話捕獲亦不等於已提煉。
- 原生 Agent 的心情仍由 dsh-feiyu-mood 注入；全域面板不借用某個會話的快照宣稱所有會話已綁定。
- 音樂只在電腦出聲不代表可回傳 Discord 音訊。原有 OneBot／QQBot／IM 交付仍受當次會話與原插件限制，這裡不新增平台外送權限。

## API 與驗證基線

`GET /api/discord-cyberfriend/capabilities`，`?refresh=1` 強制更新 metadata。沿用既有宿主身分／來源驗證。POST 不支援，沒有遠端上傳驗證紀錄端點。

`src/capability-baseline.json` 由通過的隔離測試報告及實際來源產生。載入時重新核對來源雜湊；版本變動便不沿用通過標記。這是發布內附的測試證據，不是服務商認證、簽章安全沙箱或動態第三方版本相容保證。

本次測試只使用替身服務、假庫存、隔離 HTTP 與瀏覽器。沒有付費 API、真歌下載、私人記憶寫入、Discord 測試外送或語音收聽。

診斷以宿主可見的全域服務／工具 metadata 為主；僅在特定 Agent 作用域註冊、又未提供全域快照的來源可能無法完整判定。各對象的唯讀查詢授權會分別列出；Discord 語音房與錄音訊息的開關分開處理，關閉房間收聽不等於停用錄音訊息辨識。
