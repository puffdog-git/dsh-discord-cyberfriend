# 審閱、個別偏好與本插件 Token 預算

完成日期：2026-11-12。已載入 DSH；未改變正式送出模式、套用測試預設或留下測試草稿。

## 使用入口

| 功能 | 入口與行為 |
| --- | --- |
| 自動人工接管 | 使用者帳號設定。從其他 Discord 客戶端以小號發話，暫停該帳號／頻道的 AI；預設 30 分鐘，可調整或關閉。 |

## 送出可靠性

插件送出的訊息以 nonce 與送出回執辨識，不會當成其他客戶端的人工發話。來源不確定時保守處理，不因此自動接管。

草稿保存來源版本、帳號、附件和貼圖資訊。核准時重讀原訊息，檢查來源是否改動、當前權限及帳號是否一致。來源被編輯／刪除，舊草稿失效；核准可修改文字並選擇是否保留媒體。未核准不發送，也不記作已送達回覆。

送出前先保存 sending 狀態。沒有明確回執、網路中斷或重啟時，可能轉成「送出結果不確定」，禁止一鍵重試；使用者自行核對後可封存並禁止重送。明確失敗才提供重試，避免重複發話。核准、重試都有並行鎖與版本檢查。

## 預設與偏好的界線

組合只修改選定對象的公開行為欄位，不更改 Token、管理者身分、工具權限或工作區。擷取行為組合預設不包含人格內容；若要一起擷取，可明確勾選。全域設定尚未儲存時禁止套用／擷取，避免蓋掉編輯。

同時符合多個偏好時，頻道優先於使用者；同類規則以明確指定介面、私聊／群聊者優先。留白繼承原設定。語氣和稱呼只是偏好資料，不授予命令或工具權限。

外部人格與記憶沿用 DSH 原生工作區／會話，沒有另建聊天記憶。群聊偏好可被模型用於群聊回覆，不應在群聊稱呼／語氣欄填入私人資訊。

素材的「禁止重用」仍允許理解收到的素材；不會再主動選它發送。「忽略」是審閱狀態，並非刪除。意義仍受既有作用域隔離。審閱展示現有辨識與真實使用證據，沒有新增自動合併相似 GIF 或改寫外部記憶庫的功能。

## Token 統計口徑

- 只掛載本插件模型呼叫上下文，不掛載全 DSH 的模型攔截器。
- 涵蓋可觀測的原生 DSH 回覆、直接模型呼叫、圖片辨識、分類判斷、人格日記及委派記憶寫入。不是 Discord 登入 Token 的數量。
- 優先採供應商／DSH 回報的 input、output、total usage；沒有 usage 另列估算，快取 Token 不額外重複加總。
- 以台北時區每日 00:00、每月 1 日切換統計桶；保留累計月份、最近 100 日及 2000 筆呼叫，UI 顯示最近 60 筆。不儲存提示詞或聊天全文。
- 從新版啟用開始記錄，不回補歷史帳單。估算依文字位元組、圖片數量與回覆長度計算；不可觀測的外部記憶呼叫採保守預留。
- 預算管控關閉仍記錄用量。每日／每月 0 表示不限；預設兩者皆 0，管控關閉。
- 「警告」仍允許呼叫；「阻擋」在已知新請求開始前檢查累計與進行中預留。原生 Agent 後續模型輪次也重新檢查。
- 在途請求不會因額度變更被追溯取消。失敗／中斷可能已產生成本，無 usage 時保守估算，不當作免費。

**這是 Token 管控，並非供應商帳單或硬性金額上限。** 外部插件內部二次推論可能無法完整觀測，估算與實際計費可能有落差。帳務硬上限仍須搭配供應商端額度。其他 DSH 工作不受此管控影響。

## 驗證

128 項 Node、92 項前端互動、38 項 Python、37 項隔離 REST 檢查全部通過。包含來源改動、重複核准、重啟後不確定送達、接管來源辨識、偏好優先序、並行預留、UTC+8 換日，以及原生 Agent 第二輪超額前阻擋。

實機僅背景載入與唯讀接口檢查：兩帳號 connected；四組送出模式皆 auto；待審草稿 0、自訂偏好 0、內建組合 4；預算封鎖關閉、無進行中預留。沒有向 Discord 發送本批測試訊息，沒有進行付費模型用量對帳。新 UI 互動由隔離測試覆蓋，本批未另做桌面視覺驗收。
