# 連線與對話功能更新

日期：2026-11-11。套件維持 discord.py-self 2.1.0，不需要重裝 Python 依賴。

## 使用方式

重載 Discord 賽博群友（或重啟 DSH），再登入。既有 Token、模型與回覆設定保持不變。

- 「使用者帳號 → 短暫斷線自動恢復」預設開啟。原生 Gateway Session 恢復保留去重紀錄；中斷中的舊 AI 工作取消，不重送結果不明的訊息。認證拒絕停止，短暫連接錯誤採退避，每次恢復最多 5 次 socket 嘗試／90 秒。單輪 socket 有 50 秒期限。這不能修復持續的 DNS 故障。
- Gateway 在 RESUMED 之前補送的新訊息暫存最多 100 則，恢復後才套用去重、頻道與回覆規則；期間已編輯／刪除的暫存訊息不自動回答。這不是無上限的離線收件匣。
- 「使用者帳號 → 補齊近期對話與引用」預設開啟。在需要回答的頻道按上下文設定讀取最多 20 則近期訊息，每頻道每分鐘最多一次，另外取得被引用內容。這些紀錄只供模型參考，不觸發歷史訊息回覆。關閉對話記憶或此開關就不進行補齊。
- 修改訊息會先移除本機舊內容，再取得新內容；刪除及批次刪除會移除本機紀錄。這兩種事件會取消同頻道尚未送出的 AI 回覆，避免沿用過期上下文；不自動重新回答。讀取失敗時保留空缺，不恢復舊文字。

## 表情操作

需要開啟「表情指令」、AI 自動回覆，並關閉僅觀察模式。適用監看的私訊與指定伺服器頻道。

| 表情 | 行為 |
| --- | --- |
| 🔁 | 對問題重新回答；對本次連線中產生的 AI 回覆操作時，重新讀取其原問題再回答 |
| ⏹️ | 取消該問題尚未送出的回覆並停止 typing 更新；不刪除已送出的內容 |
| 🔍 | 詳細解釋目標訊息 |
| ❓／🤖 | 沿用設定的觸發表情，請 AI 回答目標訊息 |

預設只有訊息作者能操作自己的問題及對應 AI 回覆。若需要由其他帳號操作，可填入「表情 → 額外表情操作使用者 ID」。黑白名單、頻道範圍及配額仍有效；重新回答與解釋受既有冷卻限制（預設 20 秒），停止不消耗模型／回覆配額。移除表情只更新統計，不觸發指令。

AI 回覆與原問題的對應暫存在記憶體（最多 500 筆），手動重新登入後不沿用；仍可直接對原問題操作。演練模式只生成文字，不發送。

## 取消與驗證界線

Node 端取消模型結果、待送佇列及 typing；Python 端在送出前再次檢查取消標記。已進入 Discord 發送請求的訊息無法保證撤回。宿主模型若不支援 AbortSignal，其底層生成可能繼續，但後續結果會被丟棄。

本次新增功能以離線 fixture 驗證，沒有主動發送真實 Discord 訊息，也沒有中斷正在使用的 DSH。實際 Discord 表情事件、長時間網路中斷恢復，仍需重載後驗證；先前已驗證的真實文字回覆與 typing 不等同於本批功能的線上測試。
