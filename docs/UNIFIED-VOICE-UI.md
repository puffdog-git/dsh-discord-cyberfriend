# 語音設定入口與精簡插件卡片

2026-11-13。

- 「設定 → 語音」整合「朗讀與聲音」及「語音交付」。前者保留 TTS 聲音工坊、線上／本機、聲音管理、人格與語言、進階設定；後者保留 15 個通道能力、格式限制與最近交付狀態。
- 頁籤切換不卸載朗讀表單，未儲存草稿保留；支援鍵盤左右鍵、Home／End。
- 語音交付橋接未啟用時顯示說明；僅啟用橋接而未啟用我方 TTS 時仍有獨立「語音」入口。兩者載入順序不同、單獨停用與重載皆有驗證，不要求兩個後端互相相依。
- Discord 完整介面只在「設定 → Discord」。插件已安裝清單的 row、bundle 與舊版卡片均使用精簡說明，不載入完整控制台、不輪詢 Discord 設定。原生插件啟用／停用控制仍由 DSH 提供。
- TTS「人格與語言」內的交付說明改為「在聊天軟體中使用語音」，列出 Discord、OneBot／QQBot、IM 語音泡泡／附件與啟用條件，移除主要說明中的內部服務與介面卡術語。
- Discord 下拉選單移除固定 dark color-scheme、深色底與白色選項字，改用 DSH 主題文字／背景並繼承主題模式；選取項使用同背景的淡色標示。移除背景顏色過場，避免切換主題瞬間出現白底白字。淺色／深色與系統模式交錯四組、手機導覽、使用者／Bot／語音／素材／日誌分區及停用狀態已檢查；測得文字／選項對比至少 10.8:1。這是 CSS 計算與頁面截圖驗證，不宣稱已拍到 Windows 原生彈出清單。

前端使用 `Symbol.for('dsh.voice.settings.ui.v1')` 的同頁 UI 登記，僅交換元件與變更通知，不交換帳號、API Key、聊天內容或後端能力。TTS 擔任整合頁擁有者，橋接登記交付面板；登記及訂閱均在插件卸載時清理。這是兩套我方前端的相容約定，不宣稱第三方 TTS 會自動加入此頁。

測試：Discord 97 項 client smoke、三套真實前端模組的隔離 headless Chrome（桌面、390px 手機、深色、草稿保留、鍵盤、不同載入順序、橋接缺失／卸載、獨立備援、精簡卡片不發請求、完整 Discord 頁仍可使用）通過。頁面只發唯讀請求，沒有合成、加入房間或外送。圖片已檢視；不冒稱用遠端畫面驗收了真宿主。

正常 API 重啟後三插件皆 active，宿主實際提供合併頁、精簡卡片與新版白話說明；後續選單樣式亦已從宿主資源讀回確認。memU、SenseVoice、語音房關閉及原工具允許範圍保留。證據在開發工作區 `.audit/unified-voice-ui.json`、`unified-voice-host.json`、`discord-select-theme.json`、`discord-select-theme-host.json`。
