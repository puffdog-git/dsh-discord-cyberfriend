# UI 改造與驗證（2026-11-12）

## 使用方式

- 導覽整理為「開始與連線」「人格與對象」「互動與素材」「資料與記憶」「模型與診斷」。移除沒有獨立設定的提示詞空白頁；人格設定仍在四種對象設定與 DSH 會話頁。
- 上方可搜尋全部設定。對象頁將回覆、人格、媒體、節奏拆成可展開區塊。
- 設定草稿在重新整理與自動更新後保留，可儲存或放棄。登入按鈕明確為「儲存並登入／重新連線」。GIF 試搜與模型測試使用已儲存設定。
- 部分欄位依主開關／模式停用，並顯示未生效原因。停用不會刪除原值。
- 個人帳號頁顯示 Discord self-bot 政策、小號建議與停權／封號風險，並明確不保證免於偵測或封號。
- 每日統計改讀取實際 REST 回應的 dailyStats。

## 表情與 GIF 素材庫

支援搜尋、類型篩選與分頁，不限狀態摘要原先的 50 筆。
選擇「編輯描述與用法」，可改顯示名稱、畫面描述、各群組／私聊的含義與避免情境。素材修正有自己的儲存按鈕，切換設定頁會保留草稿。

原始 AI 辨識獨立保留。手動畫面修正優先供辨識／回覆使用；留空可取消。群內含義只在素材既有範圍中檢索。AI 僅將這些內容視為素材資料，不授予命令權限。既有日記及外部記憶不會被回溯改寫。

重新辨識按鈕只清除原始 AI 辨識，保留手動修正。若要重新跑視覺辨識，先清空手動畫面描述並儲存。版本衝突回傳 409，草稿保留；請關閉編輯、重新搜尋並載入新版本。

API：GET /culture/assets；POST /culture/assets/update；POST /culture/invalidate（皆位於 /api/discord-cyberfriend）。更新欄位白名單、長度與 scope 在後端驗證；expectedVersion 防止覆蓋較新修正。群內含義更正會產生 media.annotation，沿用原有日記來源管線。

## 驗證範圍

- 108 項 Node 測試：包含實際 HTTP 素材查詢／更新、409 衝突、400 範圍拒絕、持久化、手動修正供快取與 scoped recall 使用。
- 67 項前端互動檢查：搜尋、設定相依、草稿保留／取消、登入儲存、素材編輯 API 與切頁保存。
- 23 項隔離 REST smoke；沒有對正式資料執行清空或測試設定覆寫。
- 208 個顯示設定完成 runtime consumer 靜態檢查，搭配各功能既有回歸測試；這不代表每個 Discord 權限／模式組合都已實際送訊測試。
- 正式 DSH 重啟後讀取新 schema 與素材庫成功；原有兩筆素材保留。未對正式素材寫入測試含義，未發送 Discord 測試訊息。
- 桌面逐頁視覺檢查受 computer-use 兩次「user input was detected」中斷；已停止桌面輸入。介面結構與互動由前端檢查覆蓋，仍可能需要依使用者佈景微調視覺樣式。
