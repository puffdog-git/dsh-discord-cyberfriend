# Discord 語音輸出與音樂

2026-11-13。已實作個人帳號與 Bot 的一般伺服器語音房連線、TTS 發話、文字回覆朗讀、音樂佇列、停止／離開，以及閒置自動退出。預設只輸出；Bot 可明確啟用允許名單收聽、STT 與插話中斷，不保存錄音。新增串流、音樂壓低、字幕及成本總覽見 [語音互動指南](VOICE-STREAMING-AND-INPUT.md)。

## 使用

1. 開啟「語音與音樂」，先在下方設定啟用語音並儲存。允許房間清單留空代表不限房間；填寫後只允許清單中的房間。個人帳號、機器人都適用，仍須有 Discord 查看／連線／發話權限；演練模式與個人帳號的僅觀察模式仍禁止加入／播放。
   控制台會依選擇的帳號自動取得伺服器，選擇伺服器後自動列出全部一般語音房的名稱；可按「重新偵測伺服器／語音房」更新。不會自動加入房間。手動輸入 ID 保留在折疊選項中；目前不支援舞台頻道。
2. 選 Bot 或個人帳號，載入伺服器，再載入該伺服器的頻道，選擇一般語音房；也可直接貼入 ID。每種帳號同時只加入一個房間，不支援 Stage 或私訊通話。
3. 可選填同伺服器的文字頻道。只有開啟「朗讀綁定文字頻道的 AI 回覆」後，該頻道已成功送出的 AI 文字才排入 TTS。私訊、模擬測試、其他群組／文字頻道不會廣播；先審稿須核准送出後才朗讀。文字回覆仍照常保留。
4. 手動文字可按「排入語音」。按鈕回報的是排隊成功，實際準備／播放結果顯示於房間卡。單次文字預設 500 字元、60 秒；超長文字保留原文字，不強制截斷文字。
5. 音樂可從已安裝音樂插件的本機曲庫搜尋並排入，也可填網易雲／QQ／酷狗曲目 ID。沿用音樂插件的來源、登入與音樂庫權限，不複製 Cookie 或供應商 Key。不是同步桌面播放器，也不擷取電腦／麥克風聲音。

## 閒置與停止

- **預設閒置 5 分鐘退出**，可設 1–240 分鐘。沒有 AI 發話、音樂或待播放工作時才開始倒數；完成／停止後重新倒數。查看狀態、UI 輪詢不會重置。
- 正在準備合成／音訊、播放或等待佇列時不算閒置。準備階段另有 120 秒逾時；下載有 90 秒逾時。不以其他成員是否正在說話延長最長連線時間。
- 最長連線預設 120 分鐘，可設 5–720 分鐘；即使仍播放，也會停止並退出，避免無限掛機。
- 「停止／清空佇列」取消目前合成／轉檔／播放並丟棄等待項目，留在房間等候閒置期限；「離開語音」同時停止並離開，也能取消正在建立的連線。
- 離開未確認時，顯示清理中並約每 5 秒重試，不假稱退出成功。斷線、換帳號、移除允許房間、關閉語音／插件或進入演練／僅觀察模式也清理連線。
- 重啟後不自動回房、不恢復舊播放佇列，也不自動重播失敗／不確定的音訊。

## 播放與資源

語音與音樂共用每帳號最多 8 筆等待佇列。語音保持先後順序，優先於等待音樂；若音樂正在播放，暫停後插入語音，再按原進度接續。預設暫停／接續；Bot 可選雙音軌音量壓低與漸變，詳見新版語音互動指南。

使用 FFmpeg 在本機轉成 48 kHz 雙聲道 Ogg Opus，播放不需要另載 Opus DLL。音量預設 65%，下一次準備音訊時使用新值。音樂完整下載後播放，單筆來源上限 64 MB、預設最長 30 分鐘，不是無限直播串流。轉檔輸出也有大小／時間上限，臨時檔在完成、中斷與離開時清理。

TTS 適配由 Discord 插件負責，TTS 插件只合成並回傳音訊，不需新增 Discord 接口。自動模式優先使用 `ctx.dshTts`，其後是公開 `ctx.speechSynthesis.synthesize()` 宿主服務（例如小米 MiMo TTS），其後偵測 `@goodandready/dsh-tts` 與 `@memef1f1y/dsh-plugin-tts` 的既有 HTTP API。也可在設定固定接入方式，避免多份 TTS 同時安裝時選錯。不另存 TTS 金鑰；合成失敗不自動換一家重送。

語氣提示和朗讀正文分開傳遞。語音控制台可填本次提示；留空沿用設定中的「TTS 說話語氣」。宿主服務直接收到 `speechInstruction`；新版自訂 TTS 透過中立服務接收本次指令，舊版適配使用既有試聽 API，不更改其儲存設定。其他接口不支援自然語言指令時會記錄限制，沿用原本聲音。後續已接同次回覆的上下文語氣決策，最新說明見 STAGE4-SPEECH.md。

`dsh-plugin-tts` 的 provider 選擇主要存在瀏覽器，無法直接繼承。需要 RVC／CosyVoice 等引擎時，在「TTS 進階選項」填該插件既有 API 接受的 `provider`、`custom`、`prosody` JSON。預設使用 Edge。其長文分塊會依序下載、合併成音訊；缺段時取消整段，不悄悄漏讀。這版先完整合成再播放，尚未接入邊合成邊向 Discord 推流。

每日 TTS 預算預設 10,000 字元，0 不限；按台北時間換日，提交合成時列帳，失敗不假設免費。UI 另顯示傳輸秒數，與 LLM Token 預算分開，兩者都不是金額帳單。播放完成僅代表本機傳輸完成，不能證明每位成員已實際聽到。

## 依賴與相容性

個人帳號保持原本 `discord.py-self 2.1.0`，使用其內建 VoiceClient／DAVE 與官方 voice extras（PyNaCl 1.5.0、davey 0.1.0）；未安裝要求新版核心的 discord-native-voice。

Bot 使用 @discordjs/voice 0.19.2 的 DAVE，自訂 adapter 共用現有 Gateway，不額外登入。加入 GUILD_VOICE_STATES intent，不需要新增特權 intent。音訊由 ffmpeg-static 5.3.0 提供。Node 依本插件最低版本 >=22.15，符合這版語音套件要求。

本機依賴已安裝。其他環境可先執行原 setup.ps1，再用 scripts/setup-voice.ps1 安裝鎖定 Node 依賴與語音 extras；該腳本會明確執行 FFmpeg 安裝器。控制台「檢查語音環境」只檢查依賴／TTS 設定，不加入房間或合成音訊。

## 模擬測試

`node --test tests/voice-flow.test.mjs` 以模擬 Discord 輸入、模擬模型結果和模擬 TTS 驗證文字／語氣傳遞，再經真實 FFmpeg 產生 Opus，由假 Discord 播放端攔截。完全不連 Discord、不呼叫 LLM。

如要沿用目前 DSH 的真正 TTS，執行 `node scripts/simulate-tts.mjs --base http://127.0.0.1:目前埠號 --reply "測試文字" --mood "帶笑意"`。只有 TTS 是實際呼叫，雲端 TTS 可能計費；Discord 與模型回覆仍是模擬，所有設定和用量檔都在隔離的臨時目錄。`--output` 可保存產生的 Ogg 音訊。DSH Desktop 重啟後埠號可能改變。

## 驗證界線

隔離驗證包含閒置倒數不被輪詢重置、播放中不閒置、停止合成後不晚送、文字路由防跨群／私訊廣播、TTS 字數預留、音樂中斷接續、最長連線、換帳號清理、取消連線、退出未確認重試，以及真實 FFmpeg→Opus 和 Python Opus 來源讀取。前端測試操作的是實際控制台元件與 API 參數。

138 項 Node、97 項前端、43 項 Python、41 項隔離 REST 檢查通過，共 319 項。最後的 TTS 未就緒提示變更另重跑語音與前端測試。

DSH 內嵌 Node 24.21.0 已載入新版，Bot／個人帳號均 connected；兩者語音依賴、Bot DAVE／FFmpeg 檢查通過。語音仍關閉，房間連線數 0、閒置設定 5 分鐘。

**目前 Xiaomi TTS 回報 api-key-not-configured，須在外部 TTS 插件設定 API Key／聲音後才可合成。** 不會從其他插件複製金鑰。未就緒時控制台停用手動發話，後端也拒絕排入合成，不扣本地 TTS 預算。

未進行真實語音房／遠端聽感測試，亦未花費 TTS 合成或在 Discord 播放音訊。實機唯讀結果存於 data/voice-verification.json；隔離測試與依賴可用不能當作遠端實際聽到聲音的證明。

官方參考：[discord.py-self API](https://discordpy-self.readthedocs.io/en/latest/api.html#discord.VoiceClient)、[@discordjs/voice 0.19.2](https://discord.js.org/docs/packages/voice/0.19.2)、[Discord 語音版本要求](https://support.discord.com/hc/en-us/articles/38025123604631-Minimum-Client-Version-Requirements-for-Voice-Chat)。個人帳號自動化的政策風險仍與文字功能相同，既有警語不變。


## 中日配音與人格音色（2026-11-13）

設定「語音語言」為日文配音時，公開訊息維持中文；優先採同次模型提供的隱藏日文，缺少或審稿／裁切／遮蔽變更正文時對最終文字補翻一次。沿用 LLM Token 預算、取消與快取。新版 dshTts 服務／中立 synthesize API 可攜帶 sessionId，依 TTS 的會話／工作區／人格方案選音色；明確填寫的 Discord 音色或語氣優先。舊 speechSynthesis 包裝若未宣告 contextRouting，不假稱能傳入上下文。

仍先取得完整音訊再播放，未新增 STT／錄音／真正同時混音。介面測試攔截 Discord 外送，沒有加入真實房間。


## 指定語音服務
「使用哪套語音服務」可指定語音工作室或宿主服務（如小米 TTS）。多套共存時仍依指定服務；未就緒或失敗不自動切換。
