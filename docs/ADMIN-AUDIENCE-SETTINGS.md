# 主帳號與獨立聊天設定

新增一般頁 adminUserId，依唯一 Discord ID 比對，不以暱稱或訊息文字辨認。未綁定者全部走其他使用者設定。綁定帳號加入既有表情停止／重答／解釋控制允許清單；仍受共用頻道與帳號黑白名單限制，不新增遠端任意設定命令。

四頁：管理者私訊、管理者群聊、其他使用者私訊、其他使用者群聊。私訊／群聊分開回覆開關、人格、冷卻、連續輪數、上下文、回覆延遲、引用、GIF／圖片／自訂表情理解與自動表情；群聊另有 @ 後接話、窗口、閒聊機率及監看頻道。Bot／小號共用規則，按訊息作者與聊天場景選設定。群組私訊使用群聊設定。

每日／每小時總配額、黑白名單、模型路徑、傳輸連線與總開關仍共用，UI 的黑白名單在「回覆對象 → 名單與範圍」，配額在「回覆配額」。舊設定首次正規化時複製到四頁，之後各自保存。舊主帳號冷卻豁免改由管理者頁的冷卻值設定。

78 項 Node 測試通過；前端煙霧測試涵蓋四個新頁，隔離 REST 23 項通過。尚未宣稱真實聊天室已測試管理者／其他人的不同開關。
