# Bot 與使用者帳號回覆流程檢查

日期：2026-11-11。

## 本次實測問題的原因

1. 共用 ReplyGate 只承認文字／附件，純貼圖、只有 Embed 的 GIF 預覽被視為空訊息。
2. 使用者 transport 在進入 ReplyGate 前，將未列入 userChannelIds／monitoredChannelIds 的伺服器訊息全部丟棄，包括直接 @。實際設定兩份清單均為空。
3. 實際 ledger 為 dmReplies=5、該使用者 rounds=5，已達 roundCapPerUser=5。舊程式沒有恢復期限，且反應表情也更新 lastAt；因此 GIF 甚至後續一般文字都可能只看到自動表情。舊版 info 日誌不顯示 gate 拒絕原因。
4. 第一輪線上測試又重現 GIF 的預覽更新被當成編輯：開始生成後約 0.2 秒就取消。現在比較原訊息文字／附件／貼圖；只有 Embed 補齊或附件簽名網址刷新時，僅更新預覽，不取消回覆。真正內容編輯仍會取消。

## 已對照並修正的共用流程

| 階段 | 檢查與結果 |
| --- | --- |
| Gateway 與正規化 | Bot 原本漏填 isDm、isMention，且 authorName／authorBot 不被 normalizer 接收。現在兩端共用正常化格式，保留作者、直接 @、引用作者、貼圖、附件 MIME、GIF／Embed 預覽文字。 |
| 私訊／@／閒聊分類 | 共用 classifyMessage；一對一私訊走 dm，伺服器與群組私訊的直接 @／回覆本人走 mention。無 @ 的群組私訊走閒聊規則。 |
| 頻道範圍 | 直接 @／引用本人不必先加入閒聊清單。一般插話仍須指定監看頻道、符合機率／關鍵字／最低上下文。原 userChannelIds 改名為額外閒聊監看頻道。 |
| 權限與配額 | 共用黑白名單、伺服器範圍、dm／mention／cochat 開關、冷卻與每日／每小時配額。演練模式不再跳過權限與功能開關。 |
| 指定對象冷卻豁免 | replyCooldownExemptUserIds 清單中的使用者不受私訊／@ 的 cooldownSeconds 限制；閒聊冷卻、輪數與配額仍有效。已依使用者要求將本次測試的大號加入本機設定，沒有全域關閉 20 秒冷卻。 |
| 連續輪數 | 預設仍是 5 輪，但最後一次成功回覆 10 分鐘後重置。新欄位 roundResetMinutes 可調整；roundCapPerUser=0 可關閉輪數限制，其他配額保留。表情不延長回覆窗口。 |
| 模型輸入 | 貼圖名稱、GIF 附件類型／檔名、預覽標題／描述進入相同 prompt。這是文字中繼資料理解，尚未串接視覺模型，不代表能看到動畫細節。 |
| 模型輸出 | GIF／貼圖不可用且沒有文字時，最多再生成一次純文字，避免發送空內容。使用者端不向模型宣告尚未支援的貼圖發送能力。 |
| typing／送出 | 沿用兩端 transport 的 typing／發送方式；開關依 transport 選擇，不再把 Bot 私訊誤用使用者 typing 開關。 |
| 自動表情 | 「只在伺服器頻道加表情」現在兩端都有效；黑白名單在自動表情之前也生效。 |
| 即時設定 | Bot transport 同步新的 config，避免共享回覆規則已變更但 Bot 的輸出設定仍是舊值。 |
| 診斷 | 回覆被冷卻／輪數／功能開關擋下時，info 日誌顯示 reply.skip 與原因，沒有訊息本文。 |

## 保留的介面能力差異

- Bot 的 Slash、Embed、現有自動建立討論串與貼圖搜尋／發送，未在本次替使用者端新增。使用者端普通文字、引用、GIF 連結與附件發送繼續使用 Python bridge。
- 使用者端原生 typing、重連、編輯／刪除取消與表情控制沿用上一批實作；Bot 的表情指令仍是既有路徑。本次統一的是一般訊息的輸入、分類、權限、配額、人格與回覆主流程，不宣稱兩個 Discord 介面的全部 API 等價。
- 模型仍可能輸出 NO_REPLY，既有開關／配額仍可能阻止回覆；現在有對應日誌，沒有移除所有回覆限制。

## 驗證

51 項 Node 測試與 18 項 Python 測試通過。新增兩端對照案例包含：純貼圖、GIF 附件、只有 GIF 預覽、GIF 網址、伺服器 @、引用本人、群組私訊 @；另外測試黑白名單、指定對象冷卻豁免、舊輪數恢復、自動表情範圍、GIF 失敗文字備援，以及生成途中抵達的 GIF 預覽不可取消回覆。Python 使用已安裝的 discord.Embed 檢查橋接輸出。前端 45 項檢查通過。

真實 Discord 收發結果另記於 VERIFICATION.md；離線測試不代表已通過實際平台的事件與權限驗證。
