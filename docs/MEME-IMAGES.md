# dsh-meme圖片與Discord原生貼圖

兩者分開設定，不是同一種媒體：

|來源|Discord收件人看到的內容|發送開關|
|---|---|---|
|dsh-meme圖庫|真正上傳的PNG/JPEG/GIF/WebP圖片附件|四類對象內的「允許AI發送dsh-meme表情圖片」|
|Discord伺服器自訂貼圖|原生貼圖訊息，以sticker ID發送|「反應與貼圖 → 允許自動送貼圖」|
|Discord自訂emoji|訊息內原生表情標記，由Discord解析|沿原有文字／反應策略|

## dsh-meme

已接安裝版本0.1.80的dshMeme contractVersion=1唯讀服務。用packs/search/pick選圖，由Discord插件自己選頻道與上傳。沒有呼叫可能交付QQ／其他IM的send_meme，也不把/dsh-memes本機HTTP網址交給收件人。

原本尚未連接這條路線；只有memewiki查詢與原生貼圖／GIF，不能算dsh-meme圖片交付。現在Bot與使用者帳號、DSH正式會話與獨立模型均可用。模型以MEME控制標記表達配圖意圖，原生網頁「表情」標記也能接收；後處理移除這些標記，不當作聊天文字送出。

設定位於「反應與貼圖」：顯示已啟用圖庫及ID、使用時機（只在明確要求／依氣氛）、主動機率、冷卻、允許圖庫ID、允許分類、自訂規則。四類對象分別開關，預設全關。每回覆最多一張；明確要圖仍受開關、圖庫範圍及冷卻限制。機率只限制未明確要圖的場合，並非開啟就自動每句抽圖。

只接受已啟用且在允許範圍的圖庫檔案；真實路徑／檔案識別核對、8MiB、圖片簽名與Pillow有限解碼檢查。依前30個候選篩圖，多個分類時先用首項搜尋，無命中再按分類找；不為湊圖跨出名單。

驗證後複製到本插件暫存，上傳前再核對圖庫與雜湊。正常回覆結束清理；待審稿保留至核准／捨棄，殘留最長24小時，暫存限64筆／64MiB。暫存到期請重新產生草稿。關閉或失敗時保留文字，不把選圖標記／路徑送出。語音泡泡不與表情附件混送。

圖片送達格式已用真Responder與Bot multipart圖片bytes驗證，圖片可被真Pillow解碼；Discord傳送端為替身，尚未真人確認收件人畫面。圖片附件不是原生貼圖，Discord可能顯示為一般圖片；不冒稱原生sticker泡泡。對方不需安裝dsh-meme。

## 原生貼圖的發送與理解

Bot與使用者帳號都能搜尋、手動／AI發送目前可用貼圖。使用者帳號目前只接受目前伺服器貼圖及取得的官方貼圖，不把別服自訂貼圖硬塞入發送。Bot搜尋給定文字頻道時查該伺服器，略過不可用貼圖。發送仍由Discord核對權限與帳號資格。

接收端原先只有名稱與描述，這次補上format_type：PNG、APNG、GIF原生貼圖取得其Discord CDN圖像，沿現有圖片／GIF抽幀、看圖模型／ModLens流程。使用者與Bot共通，不是只讀名稱。仍需「理解貼圖與自訂表情」及相對應的圖片／GIF辨識開關。Lottie 自 2026-11-15 起由本機 rlottie-python 1.3.8 子程序渲染抽樣圖，再交給相同看圖流程；需要開啟 GIF／動畫辨識。只接受有界、無外部資源與表達式的動畫，缺少依賴或渲染失敗則保留名稱／描述並回報原因，不假裝看過畫面。無法下載或模型不支援圖片時同樣不宣稱看過。

GIF採抽幀，不保證理解每個細節；收到dsh-meme圖片附件亦沿圖片辨識。辨識可能用模型額度，不因圖庫本身免費就代表看圖免費。

2026-11-15 實機：User／Bot 的 APNG、GIF 原生收發及看圖均通過；官方 Wave Lottie 原生發送與後續真正抽樣看圖均通過。兩張臨時群貼圖已移除。Bot 貼圖搜尋加入官方 sticker packs（五分鐘快取、有界清單、群貼圖優先）。動畫理解是取樣，不保證每個過渡動作都能辨識。
